# Crafts Corner Lebanon

The complete Crafts Corner website project and collected public photo assets.

## Website

The responsive site lives in `website/dist/`. It includes a curated 12-product catalogue, category filters, search, product/design selection, saved picks, and WhatsApp enquiries.

To preview locally with Node.js:

```sh
cd website
npm run dev
```

Open http://127.0.0.1:4173/. No dependency installation or build step is required to serve the website.

Live site: https://craftscorner.duckdns.org

## Project contents

- `website/`: source, website images, product research, preparation scripts, and browser verification results.
- `craftscornerleb_photos/images/`: 20 individual photo screenshots at Instagram-delivered dimensions.
- `craftscornerleb_photos.zip`: downloadable collection with its photo index and access report.
- `craftscornerleb_contact_sheet.png`: preview of the 20 collected images.
- `BUSINESS-SUMMARY.txt`: business description, products, and public contact details.
- `craftscorner-deployment.tar.gz`: deployment package used for the published preview.
- `PROJECT-FILES.json`: checksums of all copied project files.

The photo collection contains all slides from the four photo carousels in Instagram's public profile preview. Eight video posts were excluded. Older posts were restricted by Instagram's login requirement; this collection is not a complete historical account archive.

## Business and ordering

Crafts Corner is an online crafts and DIY shop in Lebanon, selling kits, yarn, and craft supplies. Website enquiries open WhatsApp at +961 81 254 495 for the visitor to review and send. Availability and final prices are confirmed with the store; this website does not collect payments or connect to live inventory.

Official store: https://www.craftscornerleb.com/  
Instagram: https://www.instagram.com/craftscornerleb/

Information and product data were checked on 27 October 2026. Browser verification results are in `website/qa/results.json`.
